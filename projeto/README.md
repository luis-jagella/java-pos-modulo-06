# Implementação — Projeto Prático

Branch de trabalho: `projeto-pratico`.

Esta pasta receberá a implementação acompanhando os 15 vídeos da seção Projeto Prático. Por enquanto, não contém aplicação nem instruções de execução fictícias.

## Primeiro passo

Analisar os dois Guias do Projeto Prático disponíveis no portal e registrar o objetivo, a stack, os requisitos e os entregáveis no [plano do projeto](../docs/projeto-pratico/README.md).

## Ao avançar

1. Implementar a etapa correspondente ao vídeo.
2. Registrar número do vídeo e o que mudou.
3. Adicionar comandos reais de execução e verificações proporcionais à alteração.
4. Conferir que nenhuma credencial ou mídia local entrou no commit.
5. Abrir PR para `main` quando houver uma entrega verificável.

A teoria tem branch própria: `modulo-01-software-system-design`. A referência central da disciplina está no [README principal](../README.md).
